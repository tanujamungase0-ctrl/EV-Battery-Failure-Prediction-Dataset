# EV Battery Failure Prediction

A Machine Learning project that predicts EV battery failure using battery and vehicle data.

## Overview

This project uses Machine Learning to predict whether an EV battery is likely to fail.

## Dataset

- EV Battery Failure Prediction Dataset
- Approximately 200,000 records
- Target: `battery_failure`

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Google Colab

## Workflow

Dataset → Data Preprocessing → Train/Test Split → Feature Encoding → Model Training → Prediction → Evaluation

## Model

Random Forest Classifier is used for battery failure prediction.

## Evaluation

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Feature Importance
